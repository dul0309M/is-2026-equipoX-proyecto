## 1. MÉTODOS (Técnicas Sistemáticas de Desarrollo)

- **Modelo de Proceso:** Desarrollo Incremental, ya que el sistema se desarrollará por
  partes, agregando funcionalidades de manera progresiva.

- **Técnicas de Análisis y Especificación:** Historias de usuario y definición de los
  requerimientos principales del sistema.

- **Técnicas de Validación:** Pruebas funcionales, revisiones entre compañeros y
  pruebas de los módulos desarrollados.

## 2. HERRAMIENTAS (Soporte Automatizado CASE y Entorno de Desarrollo)

- **Entorno Integrado (IDE):** Visual Studio Code.
- **Control de Versiones y SCM:** Git y GitHub.
- **Analizador Estático de Código (Linter):** Flake8 para código Python.
- **Gestión de Tareas:** Tablero Kanban en GitHub Projects.

## 3. PROCEDIMIENTOS (Estructura y Normativa Organizacional)

- **Formato de Commits:** Se utilizarán mensajes descriptivos mediante convenciones
  como `feat:`, `fix:`, `docs:` y `style:`.

- **Estrategia de Ramas (Branching):** Los cambios se realizarán mediante ramas
  `feature/*` y posteriormente se integrarán a `main` mediante un Pull Request.

- **Política de Code Review:** Cada Pull Request será revisado por al menos un
  integrante del equipo antes de realizar el Merge a la rama `main`.
